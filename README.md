# Создание одностраничного сайта на Tilda
В рамках технического задания требовалось освоить конструктор сайтов Tilda и разработать прототип одностраничного образовательного сайта (лендинга) «Учительская Кузница». 

## Задачи
* Создать сайт на Tilda
* Добавить и заполнить разделы сайта по инструкции
* Добавить дизайн блоков сайта
* Сделать скриншоты сайта

---

## Ход работы
1. Создать страницу сайта
2. Вставить необходимые блоки сайта
3. Заполнить блоки сайта текстом
4. Добавить кнопки соц.сетей, форму обратной связи
5. Сделать сайту дизайн
6. Опубликовать страницу
7. Вставить в файл с ответом скриншоты сайта и ссылку на сайт

---

## Результат
Создан сайт, демонстрирующий освоение платформой Tilda, выложенный в открытый доступ.
